# Paired-display music

The three selectable in-game loops are locally hosted and default to off. Each
is a five-minute excerpt beginning near 01:30 of its source and closed with a
2.5-second equal-power crossfade, so repeat playback has no hard cut.

| Runtime file | Display label | Creator | Source |
| --- | --- | --- | --- |
| `loops/quiet-night.mp3` | Quiet Night | Fantasy Medieval Journey | https://www.youtube.com/watch?v=dJ5VtIE3kwU |
| `loops/celtic-realm.mp3` | Celtic | Fantasy Music Studio | https://www.youtube.com/watch?v=ipFaubyDUT4 |
| `loops/waterfall-citadel.mp3` | Citadel | House of Nobless | https://www.youtube.com/watch?v=Q0rffO-LGu0 |
