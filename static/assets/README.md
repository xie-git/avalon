# Runtime artwork

Only artwork loaded by the application belongs in this directory. Files are
grouped by the screen or feature that owns them:

- `entry/` — entry-screen title and background art
- `lobby/` — shared-display lobby art
- `opening/` — game-start cinematics
- `quests/` — quest-start and quest-result cinematics
- `results/` — game-over and assassination cinematics
- `roles/` — player role cards
- `ui/` — shared interface backgrounds and card art
- `votes/` — vote-reveal cinematics

Unused and source artwork belongs in `source-assets/unused-art/`, outside the
production build context. Use lowercase kebab-case filenames for new art.
